# TUANA — موقع عطور عربية (Node.js + React + MySQL)

متجر عطور عربي (عود، خمرة، عطور، بخور) بألوان فاتحة وروح عربية أصيلة، عربي وإنجليزي (الإنجليزي بذوق إيطالي).
فيه **مقدمة متحركة** لزجاجة البرفان وهي نازلة من السما مع اسم البراند، و**صفحة دفع بالفيزا/ماستركارد**، و**داشبورد** للحسابات بفلاتر وتصدير Excel.

## 🚀 التشغيل لأول مرة على جهازك

المطلوب: **Node.js 18+** و **MySQL** (مثلاً XAMPP).

### 1) قاعدة البيانات
- شغّل MySQL من XAMPP.
- افتح http://localhost/phpmyadmin ← **Import** ← اختار ملف `database/schema.sql` ← **Go**.
  (أو من الـ terminal: `mysql -u root -p < database/schema.sql`)

### 2) الإعدادات
انسخ ملف `server/.env.example` وسمّيه `server/.env`، وعدّل فيه:
- بيانات MySQL (`DB_USER` و `DB_PASSWORD`)
- `JWT_SECRET` اكتب أي كلام طويل عشوائي

### 3) تسطيب وتشغيل
من فولدر المشروع الرئيسي:

```bash
npm run setup
```

```bash
npm run dev
```

- الموقع: http://localhost:3000
- الداشبورد: http://localhost:3000/admin

### 👥 حسابات الداشبورد والصلاحيات

| الحساب | الإيميل | الباسورد | يقدر يعمل إيه |
|---|---|---|---|
| مدير (admin) | `admin@tuana.com` | `change-me-123` | كل حاجة: المبيعات والطلبات وحالة الشحن وتعديل خطوات الشحن و Excel، المنتجات (إضافة/تعديل/حذف)، الأقسام (إضافة/حذف)، المستخدمين |
| موظف (staff) | `staff@tuana.com` | `staff-123` | يضيف ويحذف المنتجات، ويضيف أقسام بس |

- المدير يقدر يضيف مستخدمين جداد ويغير الباسوردات من صفحة **المستخدمين** في الداشبورد.
- ⚠️ غيّر الباسوردين دول من صفحة المستخدمين قبل ما ترفع الموقع.
- عايز تدي الموظف صلاحية زيادة (مثلاً تعديل المنتجات)؟ ضيفها في قايمة `staff` في ملف `server/permissions.js`.
- الباسوردات بتتحفظ في قاعدة البيانات متشفّرة (bcrypt)، مش مكتوبة زي ما هي.

> المقدمة المتحركة بتظهر مرة واحدة في كل زيارة. عشان تشوفها تاني افتح الموقع في تاب جديد.

## 💳 الدفع

العميل بيشوف بس فورم **فيزا / ماستركارد** باسم موقعك — مفيش اسم بوابة دفع ظاهر.

| الوضع | الإعداد في `.env` | الوصف |
|---|---|---|
| تجريبي | `PAYMENT_MODE=demo` | للتجربة، مفيش فلوس بتتخصم. اكتب أي رقم كارت 16 رقم (مثلاً `4242 4242 4242 4242`). |
| حقيقي | `PAYMENT_MODE=stripe` | دفع حقيقي. حط مفاتيح Stripe في `STRIPE_SECRET_KEY` و `STRIPE_PUBLISHABLE_KEY`. |

**مع Stripe:** خانات رقم الكارت والتاريخ والـ CVC بتكون خانات آمنة من Stripe بس متظبطة بنفس شكل وخط موقعك،
فالعميل مش بيحس إنه خرج من الموقع. رقم الكارت **مش بيعدّي على السيرفر بتاعك خالص** — وده مهم جداً للأمان (قانون PCI)،
وبيوفر عليك مسؤولية حماية بيانات الكروت.

للتجربة على Stripe بمفاتيح `sk_test_` / `pk_test_` استخدم الكارت `4242 4242 4242 4242` بأي تاريخ مستقبلي وأي CVC.

> ⚠️ **ملاحظة مهمة:** Stripe مش بيفتح حسابات لشركات مسجلة في مصر. لو شغلك من مصر، بوابة **Paymob** هي الأنسب.
> كل كود البوابة في ملف واحد بس: `server/services/payment.js` (دالتين: `createPayment` و `checkPayment`)،
> فلو حبيت تغيّر لـ Paymob بتعدّل الملف ده + فورم الكارت في `client/src/components/payment/`.

## ✏️ تعديلات سريعة

| عايز تغيّر | فين |
|---|---|
| النصوص (عربي/إنجليزي) | `client/src/i18n/translations.js` |
| ألوان الموقع (باليتة جاهزة) | `client/src/palettes.js` ← غيّر `DEFAULT_PALETTE` لـ: `royal` (الحالي) / `burgundy` (النسخة السابقة) / `ivory` / `emerald` / `navy` / `onyx` / `rose` |
| تفاصيل الألوان | `client/src/styles/palettes.css` و أول ملف `client/src/styles/main.css` |
| اسم البراند في المقدمة | `client/src/components/Intro.jsx` |
| رقم التليفون والإيميل | `client/src/components/Footer.jsx` |
| العملة | `CURRENCY` في `server/.env` |
| المنتجات والأقسام | من الداشبورد ← المنتجات / الأقسام |

**📷 صور المنتجات:** من الداشبورد ← المنتجات ← تعديل ← **"رفع صورة"** (PNG أو JPG أو WEBP). الصورة بتتصغّر لوحدها وبتتحفظ في `server/uploads/`.
لو المنتج مالوش صورة، الموقع بيرسم زجاجة بلون المنتج.

**🍾 صورة البرفان الكبيرة (المقدمة المتحركة + أول الصفحة):** حط صورتك باسم `hero-bottle.png` في فولدر `client/public/images/`.
أحلى حاجة تكون PNG بخلفية شفافة (تقدر تشيل الخلفية من موقع remove.bg) عشان تبان وهي نازلة من السما. لو الصورة مش موجودة بيظهر الرسم.

**🎨 الألوان:** في اللينك الأونلاين (ولما تشغّل `npm run dev`) فيه زرار **"جرّب الألوان"** تحت في الصفحة الرئيسية بتقلب بيه بين الألوان.
لما تختار اللي عاجبك اكتب اسمه في `DEFAULT_PALETTE` في `client/src/palettes.js` — والزرار ده مش بيظهر في الموقع الحقيقي للعملاء.

**🚚 حالة الشحن:** من صفحة المبيعات في الداشبورد، كل طلب مدفوع جنبه خانة **الشحن**:
- تختار منها أي خطوة، أو تدوس **"التالي ←"** ينقل الطلب للخطوة اللي بعدها على طول.
- فوق فيه عدّاد لكل خطوة، تدوس عليه يفلتر الطلبات.
- الخطوات نفسها بتتعدّل من صفحة **حالات الشحن** في السايد بار: تغيّر الاسم واللون، ترتّبها بالأسهم ▲▼، تضيف خطوة جديدة (مثلاً "مع المندوب") أو تحذف.
  - خطوة "طلب جديد" مينفعش تتحذف لأن كل طلب جديد بيبدأ بيها، وأي خطوة فيها طلبات لازم تنقل طلباتها الأول.
  - "ملغي" عمرها ما بتبقى الخطوة "التالي" — بتختارها بإيدك بس.

**لو قاعدة البيانات عندك معمولة قبل كده** ومش عايز تمسحها، شغّل ده مرة واحدة (phpMyAdmin ← SQL) عشان يضيف الشحن:
```sql
ALTER TABLE orders ADD COLUMN delivery_status VARCHAR(40) DEFAULT 'new' AFTER status;

CREATE TABLE delivery_statuses (
  id INT AUTO_INCREMENT PRIMARY KEY, slug VARCHAR(40) NOT NULL UNIQUE,
  name_ar VARCHAR(100) NOT NULL, name_en VARCHAR(100) NOT NULL,
  color VARCHAR(20) DEFAULT '#B8893B', sort_order INT DEFAULT 0
);
INSERT INTO delivery_statuses (slug, name_ar, name_en, color, sort_order) VALUES
('new','طلب جديد','New order','#B8893B',1), ('preparing','قيد التجهيز','Preparing','#C9771A',2),
('shipped','تم الشحن','Shipped','#1F5A86',3), ('delivered','تم التوصيل','Delivered','#2F6F4E',4),
('cancelled','ملغي','Cancelled','#9C3A24',5);
```

**مسح الطلبات التجريبية** قبل ما تفتح المحل (من phpMyAdmin ← SQL):
```sql
DELETE FROM orders;
```
